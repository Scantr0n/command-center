IMPORT CSV

Turn a CSV export from the real tracker file into cards.json, submissions.json, or candidates.json

← Card Grading Tracker
This page does not save anything by itself. Command Center's dashboards are static files with no database, so there is nothing here for this tool to write to directly. It parses a CSV, lets you map its columns to the real schema, runs the exact same checks as node public/cgt/data/validate.js, and then gives you a JSON file to download and use to replace the matching file under public/cgt/data/ by hand. Nothing is invented: a blank cell stays null, never a guess.

1. What are you importing?

Cards (already graded, in cards.json), submissions (batches currently at a grading company, in submissions.json), or candidates (raw cards being weighed against the cost of grading them, in candidates.json). Each has its own schema, so this changes the column mapping options and which existing file gets combined with your import below.

3. Paste or choose a CSV file

The first row must be a header row. Column names don't need to match the schema exactly, the next step lets you map each one, and any column you don't map is ignored.

4. Map columns

Guessed automatically from the header names where possible. Check each one, especially any left as "Ignore this column".

6. Validate

Runs the same rules as validate.js against your import combined with the existing real rows already on record (the example placeholder row is dropped automatically). Errors block the download below, warnings don't.

7. Download

Runs entirely in your browser. Nothing you paste or upload here is sent anywhere.
