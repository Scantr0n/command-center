IMPORT CSV

Turn a CSV export from the real tracker file into a cards.json you can save over public/cgt/data/cards.json

← Card Grading Tracker
This page does not save anything by itself. Command Center's dashboards are static files with no database, so there is nothing here for this tool to write to directly. It parses a CSV, lets you map its columns to the real schema, runs the exact same checks as node public/cgt/data/validate.js, and then gives you a cards.json file to download and use to replace public/cgt/data/cards.json by hand. Nothing is invented: a blank cell stays null, never a guess.

Checking public/cgt/data/cards.json…

1. Paste or choose a CSV file

The first row must be a header row. Column names don't need to match the schema exactly, the next step lets you map each one, and any column you don't map is ignored.

2. Map columns

Guessed automatically from the header names where possible. Check each one, especially any left as "Ignore this column".

3. Preview

4. Validate

Runs the same rules as validate.js against your import combined with the existing real cards already on record (the example placeholder row is dropped automatically). Errors block the download below, warnings don't.

5. Download

Save the downloaded file over public/cgt/data/cards.json, then run node public/cgt/data/validate.js one more time from a real checkout as a final check before committing it.

Runs entirely in your browser. Nothing you paste or upload here is sent anywhere.
