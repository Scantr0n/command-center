No live inventory wired in yet. This page is the real UI and data model, seeded with a single labeled example row so the layout can be checked, not real cards. Every card here gets individually researched, never priced in bulk. When a grade tier has no real comparable sale, that price is a clearly labeled comp-based estimate, never a silent guess and never left blank.
How to log a real card (until a backend is wired in)

Edit public/cgt/data/cards.json by hand and add an object to the cards array. Leave any field you do not have a real answer for as null, do not fill it in with a guess.

Run node public/cgt/data/validate.js after every edit. It catches duplicate ids, a missing or unlabeled valuationBasis on a priced card, a comp-estimate with no compNote explaining what it is based on, and bad dates.

A priced card gets a stale badge once its datePriced is more than 180 days old. That is not an error, card market prices just drift over months, and it is a nudge to re-check the price next time you are in this hub, not something to fix immediately.

If gradingCompany is PSA, BGS, SGC, CGC, or KSA, the card's detail view links out to that company's real cert-verification tool (PSA and BGS link straight to the cert when certNumber is filled in, the others open the lookup tool for you to enter it by hand since they don't expose a direct-link URL). HGA has no public lookup tool as of this writing, so no link is shown for it.

idUnique slug, e.g. "2021-topps-chrome-julio-rodriguez-psa10"
cardNameFull card description, e.g. "2021 Topps Chrome Julio Rodriguez RC"
sportOne of: hockey, baseball, football
gradingCompanyPSA, BGS, SGC, CGC, HGA, or KSA
gradeThe grade as shown on the slab label, e.g. "10" or "9.5"
certNumberThe grading company's cert / serial number, for looking the card back up later
estimatedValueUSD number. Leave null until it has actually been researched, never estimate in bulk.
valuationBasisRequired whenever estimatedValue is set. "recent-sale" if a real comparable sale at this exact grade was found, "comp-estimate" if none exists and the number is inferred from other grades or similar cards.
compNoteRequired when valuationBasis is comp-estimate. Plain-language note on what the estimate is based on, e.g. "No PSA10 sales found, based on 3 PSA9 sales + typical grade premium"
sourceNoteWhere the price came from, e.g. "eBay sold listings, 3 comps, Aug 2026"
datePricedISO date (YYYY-MM-DD) this card was actually researched, not today's date by default
backlogBatchOptional label grouping cards priced in the same pass, e.g. "2026-08-08-full-backlog"
