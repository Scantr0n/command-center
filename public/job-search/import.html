This page does not save anything by itself. Command Center's dashboards are static files with no database, so there is nothing here for this tool to write to directly. It parses a CSV, lets you map its columns to the real schema, runs the exact same checks as node public/job-search/data/validate.js, and then gives you a JSON file to download and use to replace public/job-search/data/applications.json by hand. Nothing is invented: a blank cell stays null, never a guess, and every imported row gets the next real free "num" automatically, the same rule the Quick log tool on the main page already uses for a single row.
This never sends anything. There is no live backend, so importing a batch can't contact anyone or apply to anything on your behalf. It only ever builds a downloadable file of applications Jack has already actually submitted, the same read-only-reference scope as the rest of this hub.

2. Paste or choose a CSV file

The first row must be a header row. Column names don't need to match the schema exactly, the next step lets you map each one, and any column you don't map is ignored. One row per application. There is no column for "num", the next free number is assigned automatically.

3. Map columns

Guessed automatically from the header names where possible. Check each one, especially pay: use the real quoted figure, or a direct quote like "Paid," no figure if that's all the posting says, never a guess.
