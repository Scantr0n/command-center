There is no live sync to eBay, Vinted, Poshmark or Depop's APIs, every number here is hand-logged. A future session with real platform access can wire live data in on top of this structure.
How to log a real update (until a backend is wired in)

Edit the JSON files by hand under public/garage/data/, then run node public/garage/data/validate.js. Leave any field you don't have a real answer for as null, do not fill it in with a guess.

listings.jsonOne object per listed item in the listings array.
idUnique slug, e.g. "black-boots"
titleItem name as it appears in the listing
priceUSD asking price, a number or null
platformsArray of any of: ebay, vinted, poshmark, depop
soldOnArray, subset of platforms, marking which of them the item has actually sold on so it can be manually delisted from the rest. Leave [] until a real sale happens on one platform while the item is still live on others.
statusOne of: draft, ready-to-post, live, sold
datePublishedISO date (YYYY-MM-DD) or null if not tracked yet. Also drives the "Relist reminders" section below, log the real date an item first went live to get relist guidance for it.
notesFree text, or null
pipeline.jsonOne object per pipeline stage in the stages array, each with a stage, integer count, and optional note.
activity.jsonOne object per logged event in the events array: real bug fixes, photo audits, and other quality checks. Requires id, title, and type (bug-fix, photo-audit, or other).
sales.jsonOne object per real completed sale in the sales array. Log a sale here and add that platform to the item's soldOn array in listings.json, both matter: this is the sale history, soldOn is what still needs delisting elsewhere.
idUnique slug for the sale, e.g. "black-boots-ebay-2026-09"
listingIdThe id of the matching entry in listings.json, or null if that listing was fully sold through and removed
titleItem name, kept here too so sale history survives the listing being removed later
platformWhich platform it actually sold on: ebay, vinted, poshmark, or depop
salePriceUSD price it actually sold for, a non-negative number (can differ from the asking price on an accepted offer)
askingPriceUSD asking price at time of sale, or null if not tracked
saleDateISO date (YYYY-MM-DD) or null if not tracked yet

Relist reminders

Platform-aware guidance on when to refresh a live listing that hasn't sold. eBay, Vinted, and Depop's search all favor listing recency, common reseller practice is to relist or renew after about 30 days without a sale. Poshmark is the exception: its Excessive Listing Removal Policy blocks relisting the same item again before day 60, doing it earlier risks the listing getting pulled instead of refreshed. This needs a real datePublished logged per item to compute anything, it stays honestly blank until then, no guessed dates.

Est. net payout by platform

Estimates only, not a live account connection. Computed from each platform's standard published 2026 seller fee schedule against the asking price above. Actual payout can differ by item category, seller level, active promotions, or a fee schedule change since this was last checked. The best tag marks the platform that nets the most for that item among the ones it's actually listed on, worth knowing if a buyer offer comes in on more than one platform at once.
Fee formulas used
eBay13.6% final value fee (standard rate, most categories) + $0.30 per-order fee, $0.40 on orders over $10
VintedNo seller fees, buyer pays a separate buyer protection fee
PoshmarkFlat $2.95 on sales under $15, otherwise 20% commission
Depop3.3% + $0.45 Depop Payments processing fee, no seller commission (US/UK)
