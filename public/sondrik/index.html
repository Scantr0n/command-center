Display tool, not a send tool. Nothing on this page contacts anyone. There is no live backend connected yet, so every number here is either a real logged fact with a cited source and date, or an honest empty state, never a filled-in guess.
How to log a real update (until a backend is wired in)

Edit the JSON files by hand under public/sondrik/data/, then run node public/sondrik/data/validate.js. Leave any field you don't have a real answer for as null, do not fill it in with a guess.

releases.jsonAppend to the releases array on every real shipped version. date is the actual ship date, summary is what actually changed.
downloads.jsonAppend a new object to metric.checks each time you actually pull a fresh count. Never edit past checks, they are a record of what was true on that date. Always state metric.source so a reader knows this isn't an estimate.
leads.jsonOne object per real lead. outreach.sent must stay false until the message has actually been sent by a human. The validator refuses a sent: true entry unless approvalStatus is also "approved".
