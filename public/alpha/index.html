Read-only, on purpose. Alpha is a real, live, money-trading daemon running on a separate machine. This page can only ever display its status, never start, stop, configure, or otherwise influence it. There is no control surface here and there never will be, if that is ever what you are looking for, it is not on this page.
No live feed wired in yet. This Command Center sandbox has no network path to Jack's Mac, where Alpha actually runs. Everything below is the real structure an overview would show, seeded honestly with "awaiting live connection" wherever a real reading belongs. Nothing on this page is a guessed number, if a field would normally show a dollar amount, win rate, or trade count, it is left out entirely rather than invented. A future session with real read access to Alpha wires live values into this same layout.
How a live connection would wire in (for whoever builds it)

This page reads public/alpha/data/status.json and nothing else. It has no API route, no websocket, and no write path, on purpose: wiring in real data means a future session writes a fresh live block into that file (for example, a small read-only export job on Alpha's own host that this Command Center pulls or receives), never adding a control endpoint here.

Run node public/alpha/data/validate.js after any edit. It rejects a live value set without live.asOf, and rejects any key that looks like real P&L, balance, win rate, or trade-count data, since this sandbox has no legitimate way to know one.

system.*Static architectural facts (agent count, feature list). Real, does not change with market conditions, safe to hand-edit only when the architecture itself changes.
connection.connectedtrue once a real feed exists and is currently reachable, otherwise false.
connection.checkedAtISO datetime of the last time connectivity was actually checked, or null.
live.asOfRequired whenever any field below it is set. ISO datetime the live reading was actually taken at.
live.regimeCurrent detected market regime label, or null.
live.killSwitch.engagedtrue / false / null if unknown.
live.positionSizing.activeModeWhich sizing rule is currently driving position size (e.g. "drawdown-based"), or null.
live.genealogy.*Current generation, count of active lineages, and last breeding event, or null until known.
